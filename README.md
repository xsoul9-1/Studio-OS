# STUDIO-OS

**Your Mac. A different experience.**

![Studio-OS Desktop](assets/desktop.png)

Studio-OS is an independent, immersive, keyboard-driven desktop environment designed for macOS.

Built around a minimal terminal-inspired interface, Studio-OS brings applications, files, web research and productivity tools together into one unified workspace.

Its visual identity draws inspiration from Roblox Studio, retro computer interfaces and modern desktop environments.

## Features

- **Custom 3D logo** — Real-time animated polygon renderer.
- **Immersive desktop** — A distraction-free, fullscreen workspace.
- **Advanced file manager** — Browse, search, preview and manage files.
- **Application launcher** — Discover and launch installed macOS applications.
- **Browser Research** — Search the web directly through Brave.
- **Custom shortcuts** — Personalize your desktop with apps, files, folders and websites.
- **Dynamic dashboard** — Switch between running and pinned applications.
- **Automatic fullscreen** — Automatically request fullscreen for launched applications.
- **Keyboard-first navigation** — Complete navigation using arrow keys or WASD.
- **Standby mode** — Enjoy the original rotating 3D logo without distractions.

## Installation

1. Download the latest PKG installer.
2. Follow the macOS installation instructions.
3. Open Studio-OS from your Applications folder.
4. Grant Accessibility permission when requested.
5. Enjoy your new workspace.

No additional Python or Qt installation is required.

## Keyboard Controls

| Key | Action |
|---|---|
| W / Up Arrow | Move up |
| S / Down Arrow | Move down |
| A / Left Arrow | Move left |
| D / Right Arrow | Move right |
| Enter | Select or open |
| Esc / Backspace | Go back |
| F | Search |
| Tab / Fn+F6 | Dashboard |
| Fn+F8 | Toggle mouse pointer |
| Fn+F11 | Toggle fullscreen |
| Q | Back or quit |

A complete command reference is available inside Studio-OS.

## Compatibility

- macOS
- Apple Silicon — M1 and newer
- Standalone installation
- Accessibility permission required for window management

## The Vision

Studio-OS was created to explore a different way of interacting with a computer.

Less distraction. Less unnecessary interface. More control.

The goal is to build an environment that feels like its own operating system while maintaining access to the applications and capabilities of macOS.
